# Minimum data request for predictive completion

The public monitoring dashboard is implemented. To evaluate actual future schedule delays and final-cost overruns, request a permitted historical export from the project owner, problem-statement sponsor or relevant ministry. Do not request credentials or bypass access controls.

For each stable project identity and scope, request:

- Historical report snapshots with original source files, provenance, units, date precision, publication/first-availability evidence, and revisions/corrections.
- Original sanctioned cost and target date, later approved baseline changes, their approval/effective dates, and scope changes.
- Actual completion/commissioning event, its scope (whole project versus stage), event date/month, supporting evidence, and when that evidence became available.
- Verified final outturn cost, cost basis and currency/unit, closure/audit evidence and known-at date. Separate estimate, expenditure-to-date and final outturn explicitly.
- Identity changes, splits/mergers, parent/subproject lineage, cancellation and suspension evidence.
- If permitted, CUF planned-progress/milestone/bottleneck history with availability timestamps, to evaluate added value over public report features.

Unknown dates and values must remain unknown; month-only dates must remain month-only. Missing projects do not imply completion. Preserve records that are still ongoing or otherwise censored so the evaluation is not limited to completed survivors.

Ask for enough earlier/later observations to construct development and untouched future-period tests, and enough distinct project families to evaluate unseen projects. Determine sample adequacy from observed coverage, outcome prevalence and uncertainty; no arbitrary accuracy or sample-size promise is justified now.

Next engineering step after receiving evidence: register new sources as separate candidates, review identity/availability and label semantics, version the eligible dataset, then train simple baselines and compare models using the frozen evaluation protocol. Deployment remains the final phase.
